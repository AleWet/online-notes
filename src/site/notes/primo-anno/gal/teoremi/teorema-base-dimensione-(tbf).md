Sia dato $V$ come [[primo-anno/gal/definizioni/def-spazio-vettoriale\|spazio vettoriale]], allora 
$$\tag{1} \exists\  \text{Base} \text{ di } V : \#B = n \implies \dim{V} = n$$
$$\tag{2} \dim{V} = n \implies \exists \text{ Base di } V : \#B = n \ \land \ \forall \ \ \text{Base di V}, \#B = n $$
