una successione è limitata se 
$$\exists M >0 \text{ t.c } |a_n| \le M \ \forall n \in D(a)$$
analogamente può essere superiormente o inferiormente limitata. Se una successione è **definitivamente limitata** allora è limitata
### successione non limitata
la negazione di questo è la seguente cosa:
$$\forall M>0  \ \exists n_0 : \forall n>n_0 \  \ |a_n| > M$$
