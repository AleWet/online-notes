si dice infinitesima una successione $a_n \text{ t.c. } a_n \rightarrow 0$

N.B.
$$a_n \rightarrow 0 \iff |a_n| \rightarrow0$$
$$\text{proof : } a_n \rightarrow0 \iff |a_n - 0| < \epsilon$$
$$|a_n| < \epsilon \ \forall \epsilon>0  $$
$$|a_n| = ||a_n| - 0|$$
$$|a_n | \rightarrow0$$
