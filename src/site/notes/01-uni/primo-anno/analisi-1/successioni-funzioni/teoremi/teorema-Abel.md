sia data una [[01-uni/primo-anno/analisi-1/successioni-funzioni/definizioni/def-serie-di-funzioni\|serie di funzioni]] $\sum_{0}^\infty a_{n}$ con raggio di convergenza $R$ dove $+\infty>R > 0$ allora
$$\text{ se } \sum_{n=0}^\infty a_{n}R^n \text{ converge } \implies \sum_{n=0}^\infty a_{n}x^n \text{ converge uniformemente in } [-r,R] \ \forall r<R$$
$$\text{ se } \sum_{n=0}^\infty a_{n}(-R)^n \text{ converge } \implies \sum_{n=0}^\infty a_{n}x^n \text{ converge uniformemente in } [-R, r] \ \forall r<R$$
$$\text{ se combini le due conseguenze hai convergenza uniforme in } [-R, R]$$
(guarda [[01-uni/primo-anno/analisi-1/successioni-funzioni/definizioni/def-serie-di-funzioni#convergenza uniforme\|qui per convergenza uniforme]])
### osservazione 1
pur avendo **convergenza uniforme** non abbiamo [[01-uni/primo-anno/analisi-1/successioni-funzioni/definizioni/def-serie-di-funzioni#convergenza totale\|convergenza totale]].
