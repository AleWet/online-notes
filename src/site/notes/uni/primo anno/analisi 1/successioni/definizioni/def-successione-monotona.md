una successione è detta *monotona*:
- crescente
- decrescente
- strettamente crescente
- strettamente decrescente

se rispetta le seguenti proprietà $\forall n$
- $a_n \le a_{n+1}$
- ...
- $a_n < a_{n+1}$
- ...

(teorema banale : se $a_n$ è monotona allora è [[uni/primo anno/analisi 1/successioni/definizioni/def-successione-limitata\|limitata]] o inf o sup o entrambi se converge)
