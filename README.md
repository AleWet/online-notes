# Online notes
## Contents

- **Analisi 1**: sequences, series, functions, sequences of functions.
- **GAL** (Geometria e Algebra Lineare): general definitions and theorems.

The notes are in Italian. Some are marked `(tbf)` (to be finished) or `(tbd)` (to be done).

## Built with

Written in [Obsidian](https://obsidian.md) and published with the
[Digital Garden plugin](https://github.com/oleeskild/Obsidian-Digital-Garden).
The site is built with Eleventy and hosted on Vercel.

## Future contributions

Fixes and new notes (definitions, theorems, proofs, examples) are welcome.
Issues and pull requests can be written in English or Italian.

**With a pull request**

1. Notes are in `src/site/notes/primo-anno/<course>/…`, one definition or
   theorem per file (`def-….md`, `teorema-….md`). Use a lowercase file name
   with no spaces or accents.
2. Copy an existing note from the same folder and keep its first three lines.
   Change `permalink` to your file's path, without `.md` and ending in `/`.
3. Write the note itself in Italian or in English, like the rest of the site, with math in
   LaTeX (`$…$` and `$$…$$`).
4. Link other notes by full path:
   `[[primo-anno/gal/definizioni/def-rango\|rango]]`.

**Without Git**

[Open an issue](https://github.com/AleWet/online-notes/issues) and paste the
text there. I'll add it to the site and credit you.
